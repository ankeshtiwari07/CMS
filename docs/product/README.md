## At a glance

- **Status:** Live in production; ~82% of tracked requirements **Met**, ~11% Partial, ~7% Gap (55 tracked).
- **Shipped:** Create Studio (multi-model, conversational), 13 generation modes incl. **real video render**, **Brand Studio**, Content Management (12 types + workflow), RBAC/ABAC, bilingual content, notifications — all live.
- **Top gaps:** Arabic/RTL **console UI**, **public site** exposure, **real image** generation, production **migrations**, real-time notifications.

> These are living documents — update alongside each release. Source of truth for "what's live" is the deployed system + the Matrix doc.
